# Assets oficiais RanTech

Arquivos oficiais copiados da pasta de marca RanTech, preservando nomes, variantes e proporções originais.

- `logo-horizontal-light.svg`: usado no shell desktop e drawer mobile sobre fundo navy.
- `symbol-light.svg`: usado no header mobile, onde a largura é reduzida.
- `avatar-dark.png`: usado no perfil do shell sobre superfície escura.
- `favicon.svg`, `favicon-32.png` e `apple-touch-icon.png`: usados nos metadados do Vite.
- Variantes `dark` e `vertical`: mantidas disponíveis para superfícies claras e futuras composições.
